# TRA-30: Next.js Project Scaffold — Design Spec

**Date:** 2026-06-18  
**Ticket:** [TRA-30](https://linear.app/tracktal/issue/TRA-30/t-026-nextjs-project-scaffold)  
**Status:** Approved

---

## Goal

Scaffold `apps/web/` with Next.js 14 (app router), Tailwind CSS, Shadcn/ui, Tremor, Recharts, and Supabase SSR client. Build must pass. Middleware protects dashboard routes.

---

## Approach

`create-next-app@14` → `shadcn@latest init` → manual installs (Tremor, Recharts, Supabase). Route skeleton and middleware scaffolded by hand.

---

## Supabase SSR Pattern

### `lib/supabase/server.ts`
Server components, route handlers, and middleware use `createServerClient` with cookie adapter.

### `lib/supabase/client.ts`
Client components use `createBrowserClient`.

### `middleware.ts`
- Matcher: `/dashboard/:path*`, `/login`, `/signup`
- Unauthenticated on `/dashboard/*` → redirect to `/login`
- Authenticated on `/login` or `/signup` → redirect to `/dashboard`
- Session refreshed on every matched request via cookie mutation
